## Article body

### 开头

```
美国 TikTok Shop 在 2025-2026 年快速增长。越来越多的中国品牌、
工厂直供 (D2C)、白牌团队想抢这一波红利。但我们在 WE Marketing 
（一家在洛杉矶的 TikTok Shop Partner Agency）接触过的跨境团队
里，前 90 天踩坑的比例非常高。

最常见的踩坑模式不是产品不行，而是用 Douyin 的运营思路套美国 
TikTok Shop。这两个平台属于同一个集团，但生态、合规、达人玩法、
买家行为都不一样。

这篇是写给计划在 2026 年进入美国 TikTok Shop 的中国品牌操盘手。
我们会讲 6 个最常见的误区，加一份 6 步落地框架。
```

### 误区 1：把美国 TikTok Shop 当 Douyin 来运营

```
表象：把 Douyin 的店播 SOP、达人合作模型、剧本话术直接搬到美国
版 TikTok Shop。

为什么不行：
- 美国达人不是机构控管的。中介式、批量买达人的模式不适用。
- 美国 TikTok Shop 的转化逻辑是创作者驱动 + Feed 信任，不是 
  店播主播主导。
- 剧本式 brief 在美国会被达人直接拒掉，他们要的是 hook 方向 + 
  自由发挥。

正解：把美国 TikTok Shop 当成一个独立的内容驱动型电商平台来设计 
SOP，不是 Douyin v2。
```

### 误区 2：合规当 marketing claim 写

```
表象：保健品、美妆、食品类目的卖家，把"治疗""治愈""预防"这种字眼
写在产品页和达人 brief 里。

为什么不行：
- 美国 FDA 对食补、化妆品、补充剂的宣称规则非常严。
- TikTok Shop 自己的合规过滤器会自动拉视频。一个被禁词就能让一个 
  达人辛辛苦苦拍的视频被下架。

正解：上线前做完整的合规审核。把每个产品的"可以说"和"不能说"做成
清单交给达人。这步省下来的时间，会在第三周以违规罚款 + 视频被拉 
的形式还回来，而且更贵。
```

### 误区 3：直邮中国货，AOV 低于 $30

```
表象：美国仓没有，所有订单从中国直发。客单价（AOV）$15-$25 的产品。

为什么不行：
- 美国买家在 2026 年期望 3-5 天到货。直邮到不了这个时效。
- 低 AOV 产品的国际运费占成本比例太高，单位经济模型不成立。
- "海外发货" 标签让转化率明显下降，复购率几乎为零。

正解：低 AOV 产品（<$30）必须有美国仓 / 美西 3PL / Fulfilled by 
TikTok。中等及以上 AOV ($30+) 可以考虑直邮 + 美国 forwarder 混合
模式。
```

### 误区 4：达人佣金按 Douyin / Shopify 标准设

```
表象：美妆、保健品类目，开放计划佣金设到 5-10%。

为什么不行：
- 美国 TikTok Shop 头部达人在美妆、保健品类目的市场佣金是 20%+。
- 设 5-10% 等于告诉头部达人"这个 brand 不重要，跳过"。
- 达人不来，cold start 起不来，算法不给流量。

正解（基于我们在多家品牌项目里观察到的范围，不是官方数据）：

| 类目                | 开放计划       | 定向头部达人      |
|---------------------|---------------|-------------------|
| 美妆                | 15-20%        | 20-25%           |
| 保健 / 食补         | 18-25%        | 25-35%           |
| 服装                | 10-15%        | 15-20%           |
| 家居                | 10-15%        | 15-22%           |
| 数码 / 配件         | 8-12%         | 12-18%           |

直播加 +5%，黑五加 +5-10%。
```

### 误区 5：用中国本地代运营做美国市场

```
表象：找一家国内代运营做美国 TikTok Shop。

为什么不行：
- 创作者网络、直播基础设施、TikTok 美国账号经理关系都在美国。
- 跨时区协作、合规细节、美国仓配等，本地团队效率高得多。
- 国内代运营在美国 TikTok Shop 上跑出来的 case 通常不多，经验
  曲线不在这边。

正解：找一家美国本地的 TSP，最好是有中文团队的。Mandarin 沟通 + 
美国本地执行 = 最顺的组合。
```

### 误区 6：英文一种语言 brief 全美投放

```
表象：所有达人 brief 用英文，所有产品页只有英文版本。

为什么不行：
- 美国 TikTok 用户里西班牙语使用者占比很高（Pew Research 公开数据）
- 加州、德州、佛州尤其明显。
- 中文族裔在美国 TikTok 用户中是稳定增长的细分，且转化率不低。

正解：进美国市场至少做 EN + ES 双语 brief。如果产品适合中文裔用户
（食品、母婴、家居、护肤），加一个 中文 创作者层级。我们在自己的 
8,000+ 创作者社群里同时覆盖 EN / ES / 中文。
```

### 6 步出海落地框架

```
第 1 步：美国 LLC + TikTok Shop 商家账号
跨境出海一般用美国 LLC 持有 TikTok Shop 卖家账号。EIN、银行账号、
卖家认证全套大概 4-8 周。

第 2 步：美国仓 / 履约
3 种主流方案：美西 3PL、Fulfilled by TikTok（如果符合资格）、混合
（中国直发 + 美国 forwarder）。低 AOV 产品强烈建议有美国仓。

第 3 步：上线前合规
- 拉每个产品的英文文案，按 FDA 规则改写。
- 建一份"禁用词清单"给所有达人 brief。
- 用 TikTok Shop Academy 的政策指南交叉校验。

第 4 步：多语言达人网络
EN + ES 是底线。如果产品适合，加 中文。从 50-100 个种子达人开始，
3 个月扩到 200-300 个。

第 5 步：90 天 cold start，找美国本地 TSP
有美国 TSP 协助 cold start 通常比纯国内团队快 60-90 天。看 TSP 
是否同时具备：达人网络、直播基础设施、合规处理、TikTok 账号经理
关系。

第 6 步：稳定后多渠道扩展
TikTok Shop 跑稳后，扩展到 Amazon US、独立站。TikTok Shop 上跑出
来的达人内容可以二次利用做 Meta / Google ads 的 performance 
creative。
```

### 选择美国 TSP 的 3 个关键问题

```
问题 1：你们有 Mandarin 团队吗？
跨境运营如果对接全程靠英文，效率会打折扣。至少有一位流利的中文
operator 是基本配置。

问题 2：你们做过几个跨境项目？类目是什么？
跨境项目有自己的失败模式（物流、合规、汇率、税务），纯做美国本地 
brand 的 TSP 可能没踩过这些坑。

问题 3：你们的 中文 创作者覆盖如何？
EN + ES 是市场底线，中文 创作者是中国品牌的差异化优势。能不能开
列出实际的 中文 创作者数量、类目分布、过往 case 是关键。
```

### Frequently Asked Questions / 常见问题

```
Q: 中国品牌一定要注册美国 LLC 才能做 TikTok Shop 吗？
A: 大部分情况下是。具体看 TikTok Shop 当下的卖家政策。技术上有
   一些其他配置可行，但运营上明显复杂得多。

Q: 中国品牌做美国 TikTok Shop 一般多久能上线？
A: 端到端 90-150 天，包括美国 LLC 注册、仓配、合规审查、60-90 
   天 cold start。如果美国基础设施已经搭好，可以压缩到 60-90 天。

Q: 中国品牌做美国 TikTok Shop 一般花多少钱？
A: 比国内 brand 美国本地 launch 贵。前 90 天大概 $60K-$150K，
   含 LLC 注册、美国仓、合规、TSP 费用、sample 投放、广告、
   直播。具体看类目和规模。

Q: 应该用中国 agency 还是美国 agency 做美国 TikTok Shop？
A: 一般来说美国本地 TSP 更合适。创作者网络、直播基础设施、
   TikTok 美国账号经理关系都在本地。一些品牌走"国内 agency 做
   总部协调 + 美国 TSP 做执行"的混合模式。

Q: 美国 TikTok 有 中文 创作者吗？
A: 有，且在增长。集中在 LA、SF 湾区、NYC 等中文族裔密度高的城市。
   网络规模比 EN 或 ES 小，但对合适的产品转化率不低。
```
