# WE Marketing — Deck UI Kit

Business-deck slide system. 1920×1080, 16:9.

Slide types:
- **CoverSlide** — title + tagline + logo
- **AgendaSlide** — numbered agenda
- **StatSlide** — big-number proof
- **ServicesSlide** — service pillars grid
- **CaseStudySlide** — brand + creator + result
- **QuoteSlide** — testimonial pull-quote
- **ProcessSlide** — 3-step flow
- **ClosingSlide** — CTA + contact
