핵심 답변: SKU를 올리기 전에 상표·저작권·디자인·이미지 사용 권리와 유통 승인을 확인하고, 승인서·인보이스·계약을 검색 가능한 파일로 보관하세요. 위반 통지가 오면 추측하지 말고 정확한 주장과 증빙에 맞춰 대응합니다.

판매 전 증빙 패키지

  1. 권리 소유: 자체 브랜드라면 상표, 디자인과 콘텐츠 권리 기록.
  2. 유통 승인: 타사 브랜드라면 범위, 지역, 채널과 기간이 명확한 LOA.
  3. 공급 경로: 법인명, SKU, 수량과 날짜가 일치하는 공급자 인보이스.
  4. 콘텐츠 권리: 사진, 영상, 음악과 크리에이터 콘텐츠의 상업적 사용 범위.
  5. 버전 관리: 현재 유효한 문서와 만료일, 담당자를 한곳에서 관리.

위반 통지 대응

범위 확인

어떤 SKU, 소재, 권리와 정책 조항이 문제인지 정확히 읽습니다.

즉시 보존

리스팅, 공급 문서, 승인서와 관련 커뮤니케이션을 보존합니다.

정확한 이의제기

관련 없는 자료를 많이 내기보다 주장별로 일치하는 증빙을 제출합니다.

재발 방지
