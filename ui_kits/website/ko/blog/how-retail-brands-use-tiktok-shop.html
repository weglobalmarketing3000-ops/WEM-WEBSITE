리테일 활용 방식

  1. 신규 고객에게 제품 사용 장면과 브랜드를 발견시킵니다.
  2. 소수 상품으로 메시지, 가격과 크리에이터 적합성을 테스트합니다.
  3. 제휴 콘텐츠를 다른 채널의 크리에이티브 학습에 사용합니다.
  4. 오프라인·DTC·마켓플레이스와 재고·가격 역할을 조정합니다.
