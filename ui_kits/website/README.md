# WE Marketing, Website UI Kit

High-fidelity recreation of the WE Marketing marketing site, bilingual TikTok Shop agency site inspired by the content structure of bemomentiq.com, skinned in WE's neon-magenta/violet brand.

## Components

| File | Purpose |
|---|---|
| `NavBar.jsx` | Sticky top nav with EN/中 toggle, logo, CTA |
| `Hero.jsx` | Full-bleed hero with neon headline + stat band |
| `ServiceGrid.jsx` | 6-pillar service grid |
| `StatBand.jsx` | GMV / brands / creators KPI strip |
| `CaseStudyCard.jsx` | Case study with brand + creator + stat |
| `Testimonial.jsx` | Quote block + attribution |
| `LogoWall.jsx` | Partner/brand logo row |
| `CtaFooter.jsx` | "Ready to go live?" footer + form |
| `Footer.jsx` | Links + social + legal |

## Usage

Open `index.html` for an interactive demo with EN ↔ ZH toggle and working anchor nav.
