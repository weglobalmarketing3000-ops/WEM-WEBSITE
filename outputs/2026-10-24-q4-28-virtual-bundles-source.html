Virtual Bundles

09/22/2026

Applies to:United States

AI Summary

Virtual Bundles is a whitelist-only feature that lets sellers sell existing products together without physical bundling, including cross-product, same-product, and split-package use cases. Eligible sellers should check Seller Center for the entry point; if unavailable, contact your Account Manager. It supports inherited sales/reviews in some conversion flows, cross-warehouse fulfillment with extra allowlisting, and batch order splitting, but unsupported items and some subscription/promo settings may be affected.

IMPORTANT NOTES:
  • This feature is currently in the whitelist phase. Some sellers have already joined the allowlist. You can check the function entrance introduced in the article to see if the function already exists. If not, please contact your Account Manager.

  1. Overview – What Is Virtual Bundle?

  • Definition:A Virtual Bundle combines multiple existing products and sold them together,without requiring the warehouse to physically package or bundle them in advance
Product Bundle – Product Bundle
(Product-level bundle)
🔥 SKU Bundle
(Supports SKU Bundles within the same product and across different products)
What I want to achieve
  • Select two products (at the PID level) to create a product bundle
  • Select any same-product or cross-product SKUs (at the SKU ID level) to combine. Individual SKUs and bundle SKUs can also be sold together.
Use cases
Product Bundle for clothing, footwear, bags, beauty sets, and more, such as:
  • Outfit bundle: top + pants in different sizes
  • Beauty bundle: lipstick + lip liner in different colors
  • Bath and body bundle: body wash + body lotion in different scents
  • 3C electronics bundle: phone case + screen protector in different colors
  • Home bundle: bedsheet + pillowcase in different colors
Fixed SKU combinations,for products with predetermined specifications, models, or styles that must be sold in fixed SKU combinations, such as:
  • Apparel set: size S top + size S pants, sold as a fixed combination
  • Skincare set: 150 ml cleanser + 50 ml face cream, sold as a fixed-size combination
  • Individual item + bundle: lipstick shade 01 + a blush shade 02 & lipstick shade 01 bundle
  • Multipacks: lipstick shade 01 + lipstick shade 01 *2-pack + lipstick shade 01 *3-pack
  • Individual item + multipack + bundle: protein powder + 2-pack of protein powder + protein powder & vitamin C bundle
Best suited for sellers
  • The seller defines the products eligible for the bundle, and shoppers select variations
  • Sellers with many SKUs and a wide range of bundling needs
  • The seller predefines the bundle contents, giving shoppers a simple selection flow
  • Best for sellers with fewer combinations and stable product pairings

How Can I Apply to Use Virtual Bundles?

  • Availability:This feature is currently available to allowlist only
  • How to apply: If the seller cannot see the entry on the Product Management page, contact your AM to request access using the form below
    • L2L:US Virtual Bundle Listing Seller Allowlist

What Sellers Can Achieve with Virtual Bundles

  • Sell cross-product bundles: Combine different products for sale (such as a top + pants or foundation + lipstick), or create new SKU combinations (such as red lipstick + orange lipstick). All products in the bundle must be ordered together; Individual items cannot be purchased separately.
  • Cross-warehouse fulfillment is supported. FBT cross-warehouse fulfillment is generally available; If you cannot use it, please reach out to your AM to contact the FBT manager to enable it. Split-package or cross-warehouse fulfillment through 3PL/4PL requires an additional allowlist request through your AM.
  • Ship oversized products in multiple packages: Products in a Virtual Bundle can be shipped from different warehouses (an additional allowlist is required). Oversized products such as sofas and air conditioners often include multiple components that must be shipped in separate packages. In these cases, Virtual Bundle supports multi-package fulfillment for these products, allowing each package to have its own tracking number so buyers can track each shipment separately.
  • How this differs from the platform's Linked Listings / Buy More, Save More features:
Similar features
Combined listingsBuy More, Save More
Difference
Linked Listings connects multiple products on the Product Detail Page (PDP), allowing shoppers to navigate between them. They remain separate products, no new PID is created, and the feature primarily groups identical or similar styles.Buy More, Save More can also facilitate combined purchases, but it is a promotion and does not create a PID. A Virtual Bundle, by contrast, is a standalone product with its own PID.

  1. Benefits of Virtual Bundles for Sellers

  • Transaction performance: Across a range of categories, Virtual Bundles generally deliver higher AOV and GPM than comparable individual product listings.
AOV: average order value GPM: sales per thousand views or impressions
  • Customer experience: Oversized products often ship in multiple packages, and shoppers may want to be able to view tracking for every package. Virtual Bundles support split-package fulfillment, allowing shoppers to track each shipment and helping reduce seller CCR.

Batch Virtual Bundle Order Splitting Function

This update introduces support for batch splitting Virtual Bundle orders. You can select multiple orders that need to be split, with a maximum of 50 orders at a time, and then click Batch Split to proceed.
After clicking Batch Split, you will be directed to the details page, where orders are grouped by Virtual Bundle item. For example, if you select 10 orders containing 3 different Virtual Bundle items, the system will display 3 corresponding Groups.
Please note:
  • If an order contains multiple Virtual Bundle items, each item will be displayed in a separate Group and must be split individually.
  • If an order contains both Virtual Bundle items and non-Virtual Bundle items, after the Virtual Bundle items are split, the remaining non-Virtual Bundle items will automatically be placed into a separate package. They will not be combined with any of the packages created from the Virtual Bundle split.
  • You need to click Batch Split for each Virtual Bundle Group to complete the splitting process.
Click Move to another package, then select Add package. After that, click any blank area on the page to complete the split. Click Next to save the changes and proceed to the confirmation step.
Once all items have been successfully split, return to the Order Management page. Orders that have been successfully split will display the Split by Seller and Virtual Bundle tags.

6.🔥 FAQs

Bundle Setup and Inventory Questions

  1. Can I split a Virtual Bundle into packages through my ERP?
  • Yes, but you must upgrade the API. See Chapter Five, Section 3 for details.
  1. Can a product with an active subscription be converted into a Virtual Bundle?
  • If a product has active subscriptions, those subscriptions will not carry over to the Virtual Bundle after conversion. Proceed with caution.
  1. How are the category and attributes of a Virtual Bundle determined?
  • The Virtual Bundle's category is determined by the category of the selected primary product. Likewise, the bundle's attributes, including keywords, are based on the primary product. This selection affects visibility of the bundle.
  1. Why do some products have the “Change to Virtual Bundle” option while others do not?
  • Gifts, certain pre-owned luxury products, and other restricted products cannot be converted.
  • Products that are already component products in a bundle cannot be converted.
  • For cross-border sellers, products listed and sold simultaneously in multiple countries cannot be converted, even if they are later changed to sell only in the US.
  • Products published through the legacy “Global Product Management” page cannot use this feature.
  1. Why does inventory show 0 after I create a bundle?
  • The component products are stored across different warehouses and do not share a common warehouse. You need access to the cross-warehouse allowlist.
  1. How do I change bundle product inventory, and why is bundle inventory not editable?
  • Bundle product inventory is calculated automatically from component product inventory. Whenever component product inventory changes, bundle inventory is updated automatically.
  1. How is bundle product inventory calculated across warehouses?
Virtual Bundle product X = 1 unit of SKU A + 2 units of SKU B.
The bundle inventory formula takes the minimum number of bundles that can be assembled from each component SKU: min(inventory of A ÷ 1, inventory of B ÷ 2), rounded down.
If the same SKU has inventory in both FBT and a third-party warehouse, fulfillment generally prioritizes FBT. When FBT is out of stock, fulfillment switches to the seller's own or third-party warehouse.

Bundle and Logistics

  1. If an order ships in multiple packages with multiple tracking numbers and one package is shipped late, will this affect the order's shipping timeliness?
  • Yes. Make sure each package is shipped on time.
  1. Can a bundle ship from both an FBT warehouse and a third-party warehouse?
  • Cross-warehouse bundling between FBT and other warehouses is not currently supported. If products in a bundle are stored separately in FBT and another warehouse, they cannot currently be combined into one Virtual Bundle for cross-warehouse fulfillment. All products in the bundle must use the same fulfillment warehouse type: either all in FBT or all in overseas warehouses.
  1. If the two products in a bundle are in the same warehouse, is shipping fees calculated under the multiple items per order rule, or is it calculated separately?
  • For FBT fulfillment, shipping fees follow the multiple-items-per-order model whether the products are shipped from the same or different warehouses. For non-FBT warehouses, split-package fulfillment is charged based on two shipping labels.

Bundle and Traffic

  1. Will converting a standard product into a Virtual Bundle affect product traffic?
  • Traffic is affected by multiple factors, including major campaigns and price competitiveness. When a standard product is converted into a Virtual Bundle, reviews and sales are retained and the PID remains unchanged. Sellers should also keep attributes, category, and other settings as consistent as possible to minimize the impact on traffic.

Bundle, Creator, and Affiliate

  1. After a standard product is converted into a Virtual Bundle, can creators still request samples?
  • After the existing listing is converted into a Virtual Bundle, creator samples associated with the old listing will show as deleted or discontinued
  1. Newly created Virtual Bundle products support creator sample requests

Virtual Bundle and Marketing Campaign

  1. Will converting a standard product into a Virtual Bundle affect marketing campaigns the product previously joined?
  • If a standard product is converted into a PID Bundle, the SKUs on the existing listing will be deleted, and product promotions will become invalid and must be reconfigured.
  • If a standard product is converted into a SKU Bundle, the SKUs on the existing listing remain unchanged. As long as the seller does not make additional changes to the existing SKUs, product marketing campaigns will not be affected.

Virtual Bundles and Backorder Products

  1. Do Virtual Bundles support backorder products?
  • Component products can currently be marked as backorder and included in a Virtual Bundle. Standard products already set to "backorder" can be converted into Virtual Bundle products. Virtual Bundle products also support other preorder tools, such as pre-order and made-to-order. See below for how to set Backorder on component product listings:

Bundles and SNS Subscription Products

  1. Can an SNS product be converted into a Virtual Bundle product?
  • It depends on the bundle type:
    • ⛑️ If a standard product is converted into a PID Bundle,the SKUs on the existing listing will be deleted, and product subscriptions will become invalid. Shoppers will be notified that their subscriptions are no longer valid.
    • If a standard product is converted into a SKU Bundle, the SKUs on the existing listing remain unchanged. As long as the seller does not make additional changes to the existing SKUs, product subscriptions will not be affected.

Bundle and FBT

  1. After converting an existing physical bundle into a Virtual Bundle, how do I fulfill it through FBT? What are the key inventory considerations?
  • Scenario 1: Component SKUs are already mapped to product IDs in FBT.
  • No further action is required. As long as the products in FBT are mapped to the Virtual Bundle and component SKU inventory is allocated to the same fulfillment center in FBT, FBT will automatically fulfill the Virtual Bundle.
  • To confirm that the component SKUs are mapped and the products have been created in FBT, go to FBT > Products
  • Scenario 2: Component SKUs have not been mapped in FBT, or no product IDs have been created in FBT
  • Sign in to the FBT Seller Portal >> Products >> Create Product
  • Create the required products in FBT and map them to the component SKUs.
  • Once mapping is complete, FBT can fulfill the Virtual Bundle.
  1. If I create a Virtual Bundle as a SKU variation under a primary product ID, how is it fulfilled through FBT?
  • To enable FBT fulfillment, go to FBT Seller Portal → Products → Create Product, and map each component SKU to a new product ID.
  • Once the Virtual Bundle's component SKUs are successfully mapped, FBT can use the associated product IDs to fulfill the Virtual Bundle.
  • Note:When a Virtual Bundle is created as a SKU variation,only the individual component SKUs (standard individual SKUs)will appear in the FBT SKU mapping list.The Virtual Bundle SKU will not appear in the FBT mapping list. See the example below.
  1. What are the FBT fees for Virtual Bundles?
  • There is no additional fee to use FBT's bundle listing feature. Sellers are charged a per-item fulfillment fee based on the number of products in the Virtual Bundle order and the weight of each product, as calculated by FBT according to its rate card.
  1. What is the FBT Multi-Fulfillment Center (FC) Virtual Bundle solution?
  • Previously, FBT sellers could fulfill a Virtual Bundle only when all component products were located in the same fulfillment center (FC) in our network. With this feature, component SKUs can ship from multiple FCs across the FBT network even when they are not stored in the same FC. Shoppers can track each package separately and view a specific estimated delivery date for each package. This feature requires access to the cross-warehouse allowlist; See Chapter Five for details.
  1. After converting an existing hard bundle to a virtual bundle in Seller Center, how can I fulfill it under FBT? What are the key inventory considerations?
    • 1. Steps for Fulfilling the New Virtual Bundle in FBT (After Converting Hard Bundle to Virtual Bundle in Seller Center) Once you create the virtual bundle and define its sub-SKUs in Seller Center, two scenarios apply:
      • Scenario 1: Sub-SKUs are already matched in FBT with Goods IDs.
        • No additional action is required. FBT will fulfill the virtual bundle automatically as long as they are matched in FBT and the sub-SKU inventory is allocated to the same FCs in FBT.
        • To confirm if Sub-SKUs are already matched in FBT, and have goods created go to FBT > Goods (refer to this guide for more information).
      • Scenario 2: Sub-SKUs are not matched in FBT yet or No Goods Ids created in FBT
        • Log in to the FBT Merchant Portal >> Goods >> Create Goods
        • Create the necessary Goods in FBT and match them to the sub-SKUs.
        • Once matched, FBT will be able to fulfill the virtual bundle.
Go to this article for more information on how to match goods.
  • 2. Old Hard Bundle Inventory Considerations After completing the virtual bundle conversion to hard bundle action in Seller Center as shared earlier in this guide, it’s important to understand how your existing FBT inventory will be affected and managed.
    Consider the scenarios below:
    • Scenario 1: The hard bundle is currently fulfilled by FBT
      • If your existing hard bundle SKU was already matched to a Goods ID in FBT, converting it to a virtual bundle in Seller Center will automatically delete the original hard bundle SKU and mark it as unmatched in FBT.Note, the historical reviews will be retained and synced on the PID level as highlighted earlier in the conversion feature.
      • Once unmatched, the inventory will no longer be sellable unless you create a new hard bundle list.
      • You can view unmatched goods in the Goods Management section of the FBT portal.
        • Scenario 2: The hard bundle is not currently fulfilled by FBT
          • If the original hard bundle was never fulfilled in FBT and no FBT inventory exists, there will be no impact on FBT inventory during the conversion.
            Important Note: Please note, if you are creating a new Virtual Bundle, make sure you create the virtual bundle before sending your inventory to FBT. This will make sure our placement engine will allocate your bundle Sub-SKUs to the same FCs for fulfillment.
            • After converting my existing virtual bundle to a hard bundle in Seller Center, how can I fulfill it under FBT ? What are the key inventory considerations?
              • Steps for Fulfilling the new Hard Bundle in FBT (After Converting Virtual Bundle to Hard Bundle/Individual Product in Seller Center) To enable FBT fulfillment for the new hard bundle SKU:
                • 1. Create a new Goods ID for the hard bundle in the FBT portal and match the Goods Id to the new hard bundle SKU that was created in Seller Center.
                • 2. Go to FBT Merchant Portal >> Goods >> Create Goods >> find SKU and match goods. Once matched, FBT will be able to store, manage, and fulfill the hard bundle in FBT.
            • Refer to this guide for more information on how to create goods.
            • Old Virtual Bundle Inventory Considerations:
              • When you convert a virtual bundle Product ID into a hard bundle, FBT will treat the hard bundle as a new standalone product SKU. The individual sub-SKUs that were previously matched to their own Goods IDs on FBT will not be able to fulfill the new hard bundle SKU but will be able to fulfill the individual SKU sales if they have standalone sales.
            • If I create my virtual bundle as a SKU variant under the main Product ID, how can I fulfill it in FBT?
              • To enable FBT fulfillment, go to FBT Merchant Portal → Goods → Create Goods, and match the individual sub-SKUs to the new Goods ID.
            • Once virtual bundle sub-SKUs are matched, FBT will be able to fulfill the virtual bundle using the linked Goods ID.
            • Note: When a virtual bundle is created as a SKU variant, only the individual sub-SKUs (normal single SKUs) appear in the FBT SKU matching list. The virtual bundle SKU will not be visible for matching in FBT. See below example.
              • What are the FBT fees for virtual bundles?
                • There is no additional fee for using the combined listing feature in FBT. Sellers will be charged per unit fulfillment fees based on the number of items in a virtual bundle order (multi-unit) and the weight of each item, as measured by FBT according to the FBT rate card.
              • What are the best practices and inbound requirements for fulfilling a virtual bundle through FBT?
                • Before sending you inbound shipments/IBR to FBT W/H, you need to make sure you create the combined listing in Seller Center, and match the sub-SKUs in the FBT merchant portal. This will make sure our supply-chain engine is able to allocate the sub-SKUs to the same FCs to fulfill them.
                • If you are creating the virtual bundle for an existing inventory in FBT network, please reach out to your Account Manager or FBT Manager first.
                • Make sure to have enough inventory for virtual bundle sub-SKUs/ Goods Ids. If one SKU is out of stock, the virtual bundle will be out of stock.
              • What is the FBT Multi-Fulfillment Center (FC) Virtual Bundle Solution?
                • Currently, FBT sellers only fulfill virtual bundles when all component SKUs are co-located in the same fulfillment center (FC) in our network. With this new enhancement, virtual bundle sub-SKUs can be fulfilled from multiple FCs across the FBT network even if all SKUs are not in the same FC, enabling shipments from different locations to the buyer. Buyers will be able to track each shipment independently, with clear expected delivery dates for each package. Refer to this article for more information.
                • If you are not included in the multi-FC virtual bundle solution, your sub-SKUs will still need to be co-located within the same FC.
              • How can I enroll in the new multi-FC virtual bundle capability in FBT?
                • We are utilizing Phase 1 as a pilot to test, and participation is limited. If you would like access to this feature or need more information, please contact your Account Manager or FBT Growth Manager. Refer to this article for more information.
